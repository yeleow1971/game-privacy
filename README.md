# Privacy Policies

Public privacy-policy pages for the mobile games published by Leow Yong Ean
(Johor, Malaysia). Google Play requires every app to link a publicly
reachable privacy policy; these are those pages.

Live: https://yeleow1971.github.io/game-privacy/

None of the games collect, store, or transmit any personal data. Pages are
generated by `build.py` — edit that, re-run it, and commit.
